# Game Maker Player («Братья Пилоты») — документация

## Обзор

Восстановленный исходный код проигрывателя Game Maker из PILOTS.EXE («Братья Пилоты: По следам полосатого слона»). Проигрыватель не содержит логики конкретной игры: он читает данные игры, дописанные в хвост собственного исполняемого файла, и исполняет их — правила классов, байт-код скриптов, фильмы, звук.

Сборка — только x86 (32 разряда): записи файла игры хранят 32-разрядные указатели, а скрипты передают адреса как `int32_t` (`_Static_assert` в `gm.h`). Сборка — `build.bat` (MSVC, C17), результат — `out\PILOTS_RE.EXE`. Если у собранного EXE нет хвоста с данными игры, он читает их из `PILOTS.EXE` в том же каталоге.

## Основные подсистемы

- **Такт игры** — цикл в `WinMain` вызывает `GmGame_Tick` с частотой кадров игры; перезапуск такта — `longjmp` на `g_RestartJmp`.
- **Правила классов** — мир состоит из тайлов-классов; на каждом такте экземпляры выполняют правила своего класса (образец, ход, скрипт, размещение).
- **Машина скриптов** — интерпретатор байт-кода (56 кодов, аккумулятор из двух регистров) и 57 встроенных функций.
- **Вывод** — 8-разрядный кадровый буфер (DIB-секция), список грязных прямоугольников, спрайты с прозрачностью и отражениями, палитра на 256 цветов, переходы сеткой и растворением.
- **Поиск пути** — волновой поиск по карте проходимости.
- **Звук** — 8-разрядный моно PCM 11025 Гц через waveOut с программным микшером, музыка в собственном формате MIDI через midiOut и мультимедийный таймер; на Win32s — шлюз в 16-разрядную GMW.DLL.
- **Фильмы** — собственный формат (дельта-кадры, RLE и LZSS) и AVI через MCI.
- **Сохранения** — автосохранение настроек и переменных и полные сохранения игры; блоки переменных шифруются XOR.

## Исходный код

| Файл | Назначение |
|------|-----------|
| gm.h | Типы формата игры, глобальное состояние, прототипы с описаниями |
| data.c | Определения глобальных переменных и постоянных таблиц |
| host.c | `WinMain` и главный цикл, окно и `Host_MainWndProc`, палитра и вывод кадра, AVI через MCI, файл данных и файлы сохранений, справка, запуск программ |
| game.c | Инициализация и завершение игры, `GmGame_Tick`, грязные прямоугольники и `GmRender_Flush`, вход в комнату и сохранение её состояния |
| rules.c | Генератор случайных чисел, преобразования клеток правил, выполнение правила, проход правил за такт |
| objects.c | Пул записей, спрайты, экземпляры, фокус, постановка и очистка тайлов, ход, раздача ввода, курсор |
| vm.c | Машина скриптов `GmVm_Run` |
| natives.c | Встроенные функции `Native_*` и таблица `g_NativeFunctions` |
| path.c | Карта проходимости `GmWalkMap_*` и волновой поиск пути `GmPath_*` |
| text.c | Печать текста глифами шрифта и ввод строки |
| heap.c | Куча движка `GmHeap_*`, временный буфер |
| load.c | Чтение файла данных, теговый поток ресурсов, применение записей, LZSS |
| save.c | Автосохранение и сохранения игры |
| frame.c | Кадровый буфер: копирование фона, вывод спрайтов, заливка, вывод в окно |
| movie.c | Проигрыватель фильмов и добавочные блиттеры кадров |
| audio.c | Каналы звука, микшер, выбор звукового слоя |
| wave.c | Звуковые слои: waveOut, MIDI через midiOut, шлюз GMW |
| pilots.rc, pilots.ico | Ресурсы: значок окна (из оригинального PILOTS.EXE) |
| build.bat | Сборка MSVC x86: `build.bat` — выпуск, `build.bat debug` — отладка |
