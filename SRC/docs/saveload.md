# Сохранения

## Общее описание

Есть два вида файлов:

- **автосохранение** — настройки и переменные, переживающие перезапуск игры; пишется и читается автоматически;
- **сохранённая игра** — полное состояние всех загруженных комнат эпизода; по команде скрипта.

Код: save.c (`GmSave_*`, `GmAutosave_*`, `GmSaveGame_*`), файловые операции — `Host_OpenSave`, `Host_SaveRead`, `Host_SaveWrite` и др. в host.c (`_open`/`_read`/`_write`/`_lseek`/`_chsize`).

## Имена файлов

`Host_BuildSavePath`: путь EXE в верхнем регистре без «.EXE» + номер слота + «.» + расширение. Автосохранение — расширение `g_Settings.saveExt`, слот `g_AutosaveSlot` (он нигде не меняется и равен 0), например `PILOTS0.230`. Сохранённая игра — `PILOTS<слот>.SAV`.

`Host_OpenSave` открывает файл на чтение и запись с созданием, **без усечения**; если не удалось — тот же файл во временном каталоге (`Host_BuildTempSavePath`). `Host_DeleteSave` удаляет файл, а если его нет — копию во временном каталоге.

## Переменные и шифрование

Какие глобальные переменные сохраняются, задают три описателя из файла игры (`GM_VAR_DESC`: число диапазонов и диапазоны `{offset, size}` в `g_GlobalVars`):

- `g_VarsKeepAlways` — всегда (и в автосохранении, и в сохранённой игре);
- `g_VarsKeepOnRestart` — при перезапуске игры;
- `g_VarsSaveGameOnly` — только в сохранённой игре.

`GmSave_WriteVars`/`GmSave_ReadVars` пишут и читают диапазоны с последнего к первому. Каждый блок шифруется XOR с 32-байтовым ключом `g_SaveXorKey`: позиция в ключе = `(смещение переменной + номер байта + 1) & 31` (`GmSave_Xor`, операция обратима). При записи блок шифруется на месте, пишется и расшифровывается обратно. Шифруются только блоки переменных; настройки и состояния комнат пишутся как есть.

`GmSave_ClearVars` обнуляет блоки по описателю.

## Начало файла

Общее для обоих видов (`GmSave_WriteHeader`):

1. магия `g_SaveMagic` — «=VS=» и версия формата `GM_FILE_VERSION_CURRENT` (0x80000016);
2. настройки `GM_SETTINGS` (52 байта);
3. блоки `g_VarsKeepAlways`;
4. блоки `g_VarsKeepOnRestart`.

Кроме магии, целостность не проверяется. Файл с неверной магией обрезается до нуля (`Host_SaveTruncate`).

## Автосохранение

`GmAutosave_Load(slot)` вызывается в конце каждой загрузки эпизода (`GmLoad_Run`):

- при первом запуске: проверить магию (повреждённый файл обрезается и пишется заново), прочитать настройки (громкости заменяются текущими целевыми), запомнить позицию блоков переменных `g_SaveVarsOffset`, прочитать блоки «всегда» и «при перезапуске», затем **обнулить** блоки «при перезапуске»;
- при повторной загрузке эпизода: перечитать оба блока с запомненной позиции.

`GmAutosave_Write(slot)`: при первом запуске (`g_FirstRun`) — всё начало файла (с `roomsVisited = 0`), иначе только блоки переменных на запомненную позицию. Вызывается перед загрузкой нового эпизода (`GmLoad_Run`, кроме первого запуска) и при завершении игры (`GmGame_Shutdown` — с признаком первого запуска, то есть вместе с настройками).

Так переменные «при перезапуске» переносятся из эпизода в эпизод (`Native_RestartGame`), но не между запусками программы.

## Сохранённая игра

### Формат

После общего начала:

1. блоки `g_VarsSaveGameOnly`;
2. для каждой загруженной комнаты: номер комнаты, число записей пула, карта тайлов (`mapWidth × mapHeight` слов) и записи пула (`GM_POOL_ENTRY`), затем блоки переменных экземпляров, у которых они в куче.

Указатели кадров спрайтов пишутся смещениями от начала арены (`GmSave_RebaseSpriteFrames`) и при чтении превращаются обратно в адреса — арена при перезагрузке занимает ту же память. Блок переменных экземпляра пишется длиной `varsSizeMinus1`, так что его последний байт не сохраняется (особенность оригинала).

### Запись — `GmSaveGame_Save(slot)`

Сохранить текущую комнату (`GmRoom_SaveState`), занести в настройки частоту и счётчик кадров, число загруженных комнат, эпизод и комнату, записать файл, вернуться в комнату (`GmRoom_Enter(…, true)`). Файл не усекается: короткое сохранение поверх длинного оставляет хвост старых данных.

### Чтение — `GmSaveGame_Load(slot)`

1. Проверить магию; прочитать настройки, оставив текущими включённость звука, ввода и фильмов.
2. Загрузить эпизод из настроек в режиме `g_LoadingSave`: комнаты не строятся, настройки по умолчанию и автосохранение не читаются, вход в комнату не выполняется.
3. Прочитать блоки переменных и состояния комнат.
4. Войти в сохранённую комнату, восстановить частоту и счётчик кадров, музыку (`Native_PlayMusic`) и курсор.
5. Перезапустить такт (`GmGame_Restart`) — при успехе функция не возвращается.

### Из скриптов

`Native_SaveGameOp(slot, action)`: `GMSAVEOP_DELETE` — удалить, `GMSAVEOP_SAVE` — сохранить, `GMSAVEOP_LOAD` — загрузить.
